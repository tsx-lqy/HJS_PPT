# 重点标红、加粗与图中定位

这一规则用于内容页的文本 run 和图中标注，不只用于页标题。默认沿用参考稿的深红 `#C00000` / 用户模板红色；用户明确限制蓝色等配色时，用对应强调色实现同样层级。不能为统一配色改写科学曲线或光路图的颜色语义。

## 参考稿中的实际层次

- 方法与方案页常以**黑色粗体**标出器件、方法名和步骤关键词，句中关键参数、差异或选择依据再标红。
- 对比/结果页把 ROI 框、图中关注位置和解读中的关键词对应，结论区突出核心判断或有证据的关键数值。
- 部分会议与复试页用红底黄字形成强结论条。这是高强度变体，不适合每页重复；白底正文默认使用局部红色粗体。
- 图内的红色文字、虚线框和引线用于定位具体结构；整段染红会丢失这种定位作用。

## 默认执行

每页确定读者最应记住的判断，并列出需要强调的短语。一般先选 1–3 处；这只是注意力预算的起点，不是字数或次数硬指标。

| 文本角色 | 默认处理 | 示例（示例数值不是实验结果） |
|---|---|---|
| 步骤/方法名称 | 黑色粗体，必要时红色小标题 | **深度集成**、**线聚焦探测器** |
| 核心机制/差异 | 正文中的短语标红且加粗 | “由 **[红]模型间分歧[/红]** 提供代理” |
| 关键参数与比较量 | 数值、单位、对应基准一起理解；重点 run 红色粗体 | “在相同条件下，采集时间为 **[红]12 s[/红]**（教学示例）” |
| 条件和限制 | 就近保留；影响结论时也可红色粗体 | “该保证仅适用于 **[红]同分布条件[/红]**” |
| 普通解释、引文与来源 | 深灰/黑色常规字重 | 不让整行出处抢过主图 |

`[红]` 只是本说明中的标记，不得输出到 PPT。实现时将同一段拆为多个原生文本 run，对重点同时设置 `bold=true` 与颜色；保持同一句其余文字的字号与基线一致。Markdown 的 `**` 不能自动证明 PPT 里已经加粗。公式内强调必须在 MathType 中处理或使用旁边的原生说明，不能覆盖、切碎或栅格化公式。

例：

- 普通黑字：“模型内方差描述”；**红色粗体**：“观测噪声”；普通黑字：“，模型间分歧反映”；**红色粗体**：“模型不确定性代理”；普通黑字：“。”
- 不要整段标红、每个名词加粗，或为了强调删掉“代理”“在当前数据上”“相同条件”等限制。
- 强调箭头只指向一个明确对象；结果图必须使用同一 ROI，重点颜色与图例一致，不给表现未知的方法添加“最佳”色。

## 验收

保存后检查文本对象中的实际粗体和颜色，再看渲染：重点是否一眼可见、是否与主图对应、是否有相邻的条件说明、是否因为红色太多而失去层级。PPTX 中继承自主题/母版的样式也要按最终显示核对；不能只数红色对象。整页、复杂图与局部重点分别放大查看。WPS 中再检查字体替换和红色对比度。
