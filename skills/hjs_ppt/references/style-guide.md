# 视觉与表达规则

这里记录六份去重参考稿的观察与面向新稿的建议。公开版的适用范围和素材处理见 [design-notes.md](design-notes.md)。

## 先分离模板与主体

原稿均为 13⅓ × 7½ 英寸（16:9）。COME 使用红色通栏标题及会议标识；中文长汇报使用顶部章节导航和底部色带；组会稿使用章节编号、细红线及校园轮廓。这些是模板外壳，不属于必须复用的主体风格。

主体中的编号解释、局部虚线分组、ROI 标注和结论条是内容组织手段，可以迁移。长汇报中的页内小步骤列表也可以迁移；顶部全局章节导航仍由模板决定。主体小标题前的箭头或菱形只是可选标记，不复制原稿的固定装饰。

## 观察到的共同特征

| 维度 | 原稿中的规律 | 新稿如何应用 |
|---|---|---|
| 底色 | 内容区以白色为主，黑色或近黑正文 | 保持图表的视觉优先级，避免大面积装饰背景 |
| 信息层级 | 黑色加粗主问题；红色分项或关键词；普通解释；小号符号注释 | 同一层级用同一字号、字重和间距 |
| 图文关系 | 主图常占半页以上，旁边或下方有简短解读 | 为读图路径排版；不把图缩成文字段落的配图 |
| 模块边界 | 细灰线、红色细线或虚线、浅粉小标题带 | 仅在需要说明组成、对比或范围时使用 |
| 论证方式 | 总体图、局部放大、曲线或指标、文字判断相互印证 | 让观众知道“看哪里”和“这说明什么” |
| 技术绘图 | 真实器件照片、功能示意、网络模块、公式并用 | 按问题选择表征方式，不用泛用装饰图标替代机制 |

上述“半页以上”是视觉概括，不是对每页做像素分割后的统计结果。

## 字体与大小

实测的显式字体中，微软雅黑在参考稿里占主导；COME 图内有 Arial，部分公式、英文及既有插图保留 Times New Roman、宋体等。新增文献组会常见 19–20 pt 解释和 16 pt 辅助文字。不要因频数就把原稿所有字体混用继承下来。

16:9 普通投影场景可从下列区间起步。它们是结合原稿的建议，不是强制字号标准；模板和观看距离优先。

| 角色 | 建议起点（pt） | 依据 / 用法 |
|---|---:|---|
| 页面标题 | 沿用模板；无模板时约 26–30 | 原组会标题常为 26–28，正文小标题不应抢过它 |
| 页内问题 / 分项标题 | 20–22，加粗 | COME 主体小标题常 21，长汇报常 22，组会常 20 |
| 解释正文 | 16–22，优先 18–20 | 组会解释常 16，长汇报较多 20；密度随内容调整 |
| 公式主体 | 20–24 | 独立行放置，保留正确上下标和数学结构 |
| 图注 / 变量说明 | 12–16 | 承担辅助说明，不塞入必须远处读到的核心信息 |
| 结论 / 关键数值 | 20–28，可局部放大 | 先强调结论中的差异或数字，不放大整段 |

尽量使用微软雅黑或模板指定的可用无衬线字体。所有公式必须使用 MathType，按 [公式规则](mathtype.md) 保留编辑能力，并在 MathType 内设置数学字体和字号。字号单位为点；使用像素 API 时需换算，不能把 pt 数值直接当 px。

原稿中确有 5–11 pt 的图内字、密集表格以及更小的细节。这些是可读性边界或素材内部结构，不能成为新稿正文的默认字号。

## 颜色的语义

下列色值来自原稿 OOXML 中的显式颜色；主题继承和嵌入图片有自己的颜色，不把频数当成精确视觉面积。

| 用途 | 参考值 | 应用方式 |
|---|---|---|
| 主文字 | `#000000`，`#202020`，`#202632` | 主体内容以深色为底 |
| 重点 | `#C00000` | 分项标题、关键差异、最优项或结论中的关键词 |
| 次级红色变体 | `#BE2619`，`#A91B2D` | 分别见于 COME 和组会；新稿通常选择一种即可 |
| 轻提示底色 | `#FDE0E0`，`#FCDDDD`，`#F8CFCC` | 小结、表头、模块名带，保持文字清晰 |
| 辅助线 / 弱内容 | `#BFBFBF`，`#A6A6A6` | 分隔、虚线框、尚未讲到的步骤 |
| 弱背景 | `#F7F8FA` | 可选的轻分区，避免每段都装进卡片 |

有用户指定的蓝色等模板时，将强调、浅底、细线的语义映射到模板配色，保留层级关系。不要强行换成川大红。科学图像伪彩、方法曲线色、物理路径色已有含义时保留并说明图例，不为了统一红色而重染。

COME 的少量结论页使用红色渐变带、白字及黄色数字，这是会议场景的强强调变体。普通新稿可优先选浅粉底黑字、红色关键值；用户要贴近 COME 时才保留相应强度。不要给所有内容加渐变、阴影和黄色高亮。

新增历史讲解段落使用黑底、白字、黄色当前年份和贯穿多页的时间线。这是可选的专题变体，不改变白底技术页的默认建议。保留用户模板时，用强调色和弱化前后节点实现相同导航；不要自行插入黑底章节。历史示意中的弧线、人物及脑图属于特定内容，不能当成通用装饰。

## 空间与密度

- 先确定模板保留区，再定义可用主体矩形。参考稿主体大体在整页上方模板下、底部模板上；不可直接复用原稿绝对坐标到其他模板。
- 以主体矩形为单位布局。常用主图 / 解读约 55:45、65:35；两种方法对照约 50:50。它们是可调整的设计起点。
- 两栏间建议留主体宽度约 2%–4% 的间隔。若加结论条，可预留主体高度约 8%–12%；没有结论条则把空间还给图。
- 原稿偏“技术讲义式高信息密度”，但结构清楚。不要改成只有一句口号的海报，也不要照搬论文整页截图和长段图注。
- 相似内容对齐标题、图边缘、方法标签和基线。并排图使用一致比例；保留真实裁剪、坐标和尺度含义。

## 文字与证据

正文重点默认采用**局部标红并加粗**：方法差异、核心机制、关键参数/数值或决定结论适用范围的限制。步骤名可只用黑色粗体，普通解释维持黑/深灰；不要把“重点”仅实现为红色小标题。文本 run 的具体写法、图中定位和验收见 [重点强调](emphasis.md)。

主体的视觉丰富度主要来自**有语义的素材**，而不是更多边框：器件、层叠特征、图像栈、实物照片与标注、同源局部放大及测量组合。制作前浏览 [素材库](asset-library.md)，需要时按 [生图流程](image-generation.md) 补充概念插图。抽象组件也应能让观众识别“这是什么”，不能全部用同形矩形替代。

概念页常见结构为“编号 + 模块名称 / 一个关键公式 / 作用解释”，并在页底提示局限或区别。系统页常见“方案 / 器件 / 优缺点 / 选择依据”。结果页常见“条件 / 图像与 ROI / 指标 / 结论”。选择匹配内容的一种，不把这些字段机械地显示成表单。

用明确名词和短句，优先回答物理过程、输入输出、状态变化、实验差异。已有图能说明的关系无需再抄一大段正文。每个强调词都应对应一个真正的选择、机制或证据点。

## 新增稿体现的制作方法

- **原理先具体后抽象**：以小规模算例或图示解释过程，再合并为公式。矩阵的行列标注紧贴矩阵，明确对应采样点、波长或分量；不要只放一个缩写等式。
- **一篇文献一条证据链**：来源置于主体顶部，主要系统图占大区，右侧紧邻结果和作者解读；引用不是装饰性标题，也不能让长作者列表挤压证据图。
- **图中语义与文字一致**：光路、声路、信号线分别用固定颜色或线型；ROI 框与曲线颜色对应。色彩还应有标签辅助，不能只靠红绿区分。
- **方案总结维度一致**：方案名占窄列，优势、代价或限制形成对齐的宽列；从同一需求出发比较，并给出有条件的选择，而不是堆砌优点。
- **连续页面共用参照**：流程、时间线、方法顺序和 ROI 位置保持稳定，只高亮本页焦点。优先静态分步页面，动画并非必要能力。

原参考中存在密集表格、长引文和术语标注不一致；这些应在新任务中核对或修正，不能因为来自参考稿就照抄。

## 复试与答辩稿的补充规律

- **能力和职责需要证据落点**：经历页用照片、活动说明和成果记录支撑；项目表将项目名称、类别与本人职责对齐。迁移的是对应关系，不是作者的履历、分数或荣誉。
- **先讲机制，再看实现**：系统示意、扫描结构及同步时序在一页构成解释；相邻页以实物照片和就近标签对应这些模块。保持两页术语一致，减少引线交叉。
- **横向研究版图贯穿当前与未来**：先标出当前工作，再沿用同一分类说明拟扩展方向；高亮是定位，不等于已经完成所有模块。
- **步骤行比大段叙述更便于检查**：同一行放步骤、原理或选型理由、对应示意。读者可横向理解一项，再纵向查看整个过程。
- **成果状态和研究计划分开**：已完成的工作、正在分析的结果、投稿状态与预期成果分别表述。源稿中的期刊影响因子、分区、年份和数量不作为通用事实继承。

新增参考的显式正文以 18、20、16 pt 为常见值，仍沿用本指南的可读性建议。红色通栏、日期、目录高亮属于模板；渲染时动态日期字段可能显示当前日期，不能据此改写材料的实际时间。

复制排版规律不等于验证原论文。原稿中的“临床图像质量”“66×”“76%”“100%”等主张只能作为视觉样例；新稿必须由新任务的材料支持，特别注明比较基准、单位、实验条件和统计范围。
