# 提炼依据与公开版边界

## 样本与方法

本指南最初从三份科研汇报共 71 页中提炼：一份 19 页英文会议汇报、一份 38 页中文系统研究汇报、一份 14 页中文世界模型组会稿。比较了静态渲染结果、逐页文本、形状、显式字体与颜色。

2026-10-25 扩充时检查三份输入共 58 页：25 页的文献与深度学习发展史组会、19 页的 COME 会议汇报、14 页的多光谱方案组会。COME 与先前输入的 SHA-256 相同，只计一次。因此目前为 **5 份不同文件、110 页**；页数包含封面、过渡及附录，并不意味着 110 页全部属于主体样本。本轮三份文件全部用 PowerPoint 逐页渲染，结合接触表、重点页及 OOXML 信息提炼。源文件名中的日期不被当作研究发表时间。

封面、目录、致谢、结束页，以及校徽、会议标识、章节导航、页眉页脚等模板外壳不作为必须复刻的主体规则。正式内容页的共同规律优先于附录中的高密度表格和小字号。

## 三类样本的贡献

| 类型 | 主要贡献 |
|---|---|
| 会议汇报 | 问题到方法到结果的短论证链，图像与指标配合，多方法比较 |
| 系统研究汇报 | 总框图到模块拆解，技术方案取舍，采集与控制时序，实物与测量 |
| 概念组会 | 从直观问题到结构和公式，编号解释，训练闭环，关键区别与小结 |
| 文献与发展史组会 | 预处理步骤、带算例的机制解释、同位置 ROI 与曲线、跨页时间线 |
| 多方案文献组会 | 引用条与系统图同页、矩阵维度解释、机制到实例、优势与限制对照 |

这些规律可以迁移到其他学科；无需沿用原稿的研究题材、人物、标题或结论。

## 观察与建议分开

`style-guide.md` 中的字体和色值来自原稿可读属性；列宽、间距与结论区比例是便于复用的建议区间，不是逐像素复刻的硬性标准。用户提供的模板、观看距离、内容复杂度和明确要求优先。

不继承可见性较差的小字、密集附录、冗长图注、编辑批注或隐藏文本。静态检查不代表验证了原稿的动画、视频、链接目标或研究正确性。

## 为什么公开版使用自绘示意

原稿包含研究图像、实物照片、机构标识及各自的内容来源。公开版不需要这些具体内容就能表达排版方法，因此只分发重新编写的风格规则与原创 SVG 示意。

SVG 使用通用模块、图像占位、公式标签和指标占位，未嵌入原稿像素或实验数据。示意中的 `value`、`ROI`、`equation` 等字样仅说明该位置应承载什么内容。新增算例中的 2、3、4 等是明确标注的教学数据，不是参考稿的实验结果。制作实际演示文稿时，用用户的材料替换，并核对来源、单位、比较条件和结论支持。

## 制作能力的来源与边界

材料转换、原生公式与图表、讲稿随页面关联、导出后视觉检查的工作流参考 [PPT Master](https://github.com/hugohe3/ppt-master)。本仓库独立编写适合科研主体页的指令、例子及检查脚本；没有复制或捆绑它的转换引擎。接入版本、可选依赖及能力边界见 [ppt-master-integration.md](ppt-master-integration.md)。动画、配音和视频导出不属于本次集成。

本 skill 独立于特定大学、会议或作者；名称中的 `scu` 用于保持 skill 标识稳定，不代表机构发布或背书。
